# 异常通报

## 组织方式

一个异常一个 Markdown 文件，按年份建子目录。文件名优先用官方通报号；没有通报号时用 `站点缩写-YYYYMMDD-序号`。

```
异常通报/
├── README.md          ← 本文件，脱敏规则与总索引
└── 2026/
    └── GCFK202612995.md
```

## 脱敏规则

- 厂站名称：省市 + 站名首字母，保留电压等级，例如 `HNZMD ±800kV YNHLS`；仓库内不保留对照表
- 人名：姓名首字母，例如 `HA`
- 不入库：截图、图纸、报价、内部系统地址
- 保留：装置型号、程序版本、管理序号、通报号（技术检索需要）

## 新增一条异常

1. 复制 `_模板/异常通报记录.md`
2. 在 `异常通报/<年份>/` 下新建 `<通报号>.md`，填入字段、事件过程与通报原文
3. 在本文件的总索引表里加一行
4. 本地提交，提交信息格式：`异常通报: <站点缩写> <通报号>`
